How is this calculated?

GitHub Copilot bills models in AI credits: 1 credit = $0.01. Each model has a price in credits per million input tokens and per million output tokens. With a share r of input tokens:

blended price = r × input price + (1 − r) × output price
tokens = budget in credits ÷ blended price × 1,000,000

  • Caching is not included. Cached input tokens are billed about 10× cheaper than fresh input, so agent sessions that resend the same context get more out of the budget than shown here.
  • Per working day divides the monthly budget by 21 working days (5 days a week). Weekends and holidays are not counted.
  • Long-context tiers apply to requests whose prompt passes the model’s threshold. They are hidden by default; turn them on above to see how much they cut the budget.
  • A request is counted as 50,000 tokens in the tooltip, a rough size for one agent step that sends files and conversation history. Actual sizes vary widely.
