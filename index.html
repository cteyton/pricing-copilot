Three habits that make credits last

  • Start small, step up if needed

    Try the suggested model first. Switch to a stronger one only when the answer isn’t good enough, not by default.

  • New topic, new chat

    Every message re-sends the whole conversation to the model. A long thread makes each new question more expensive.

  • Share only what’s needed

    Each file or document in the context is read again at every step. Attach the spec you are working on, not the whole folder.
