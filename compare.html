    How is this calculated?

    Prices. GitHub’s list prices in AI credits per million tokens (1 credit = $0.01), with the US dollar price in brackets. Cached input is what a token costs when the same prompt prefix was sent recently and the provider reuses it; cache write is what some providers charge to store that prefix the first time. Some models charge more per token once a single prompt passes a threshold: those rates are in the Long context section.

    Blended price. r × input + (1 − r) × output, with r the input share of the mix (90% by default, as coding agents read far more than they write). Default tier, without caching.

    Agent request. 50,000 tokens at the blended price: one agent step that sends files and history and gets an answer back, in AI credits.

    Scores. Artificial Analysis Intelligence and Coding Index, at the effort named under each score (High when available). The rank counts every Copilot model with that index. Coding points per 100 credits is the Coding Index divided by the blended price of 1M tokens, counted in hundreds of credits; on the frontier means no cheaper Copilot model has a higher Coding Index at this mix (see 3 · Value).

    Baseline. Gaps are measured against the baseline column: ×N for prices (lower is better), points for scores. Click Set as baseline under a model to change it.
