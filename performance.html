    How is this calculated?

    Price. GitHub’s list price per million input and output tokens, blended by the mix: r × input + (1 − r) × output, with r = 90% by default, because coding agents read far more than they write. Default tier only: long-context rates and caching are left out.

    Score. An Artificial Analysis index, picked with the Score switch. Coding (default) is their composite of coding benchmarks (e.g. Terminal-Bench, SciCode); recent models often get it a few weeks after release. Intelligence is their broader composite of reasoning, knowledge, maths and coding, published sooner. Models without the selected index are listed under the chart.

    Artificial Analysis benchmarks each model at several reasoning efforts. This page uses High; when a model has no High result for the selected index, the nearest one (Xhigh, then Medium, Max, Low). The tooltip names the variant used.

    Frontier. Sort the models in view by price. A model is on the frontier when it scores higher than every cheaper one. The frontier is recomputed when filters or the mix change.

    • The index measures the model, not Copilot’s harness around it, and reasoning effort changes how many tokens a task uses: a higher score can cost more tokens per task than the blended price suggests.
    • Two Copilot entries can share one score (e.g. Claude Opus 4.8 and its fast mode, which costs twice as much).
